## 2. 当初の仮説は否定された

### 仮説：「配信本数を重ねるとPVが伸びる」→ **誤り**

情報通信（22,748社）で、その企業にとって何本目のリリースかを軸にPV中央値を出した結果：

| 何本目 | 母数   | PV中央値 |
| ------ | ------ | -------- |
| 1本目  | 22,748 | 13       |
| 2本目  | 16,504 | 12       |
| 3本目  | 13,592 | 12       |
| 6本目  | 9,247  | 12       |
| 8本目  | 7,825  | 12       |

**完全に横ばい。** 本数を重ねても1本あたりの反応は良くならない。

これにより、当初設計していた `eval_point`（1本目の1.5倍に届く本数）は
**このデータでは算出できない**ことが確定した。

### 仮説：「メディア転載率で差がつく」→ **誤り**

`webclipping_list` を10万本サンプルで集計した結果：

| 転載件数      | リリース数 |
| ------------- | ---------- |
| 1〜5件        | 108        |
| 6〜20件       | 1,710      |
| **21〜100件** | **69,755** |
| 100件超       | 163        |

**ほぼ全リリースが21〜100件転載されている**（パートナーメディアへの自動配信と推測）。
転載の有無や率では企業間の差がつかないため、指標として使えない。

## 3. 代わりに見つかった指標

### PVは極端に裾が長い

情報通信のPV分布：

|         | 値    |
| ------- | ----- |
| 中央値  | 25    |
| 上位10% | 128   |
| 上位1%  | 1,487 |
| 最大    | 8,092 |

**上位1%は中央値の約60倍。** つまり1本ごとが「くじ」であり、
平均を上げるのではなく、**当たりを引く確率**で考えるべき構造。

### 中心指標：配信本数別「当たりを引いた企業の割合」

「当たり」＝業種内PV上位10%（情報通信では50PV以上）に、1本でも届いたこと。

| 配信本数 | 企業数 | 当たりを引いた割合 |
| -------- | ------ | ------------------ |
| 1本      | 6,244  | **17%**            |
| 2本      | 2,912  | 24%                |
| 3本      | 1,974  | 29%                |
| 4〜5本   | 2,371  | 37%                |
| 6〜10本  | 2,836  | 47%                |
| 11〜20本 | 2,074  | 60%                |
| 21本以上 | 4,337  | **87%**            |

**単調に増加する、きれいなカーブ。** これが本プロダクトの中心指標。

意味するところ：

> 1本の結果で「効果がない」と判断するのは早すぎる。
> 1本しか出していない企業の83%は当たりを引けていない。
> それは企業側の問題ではなく、試行回数の問題。

## 4. 時間では上がらない。本数でしか上がらない

初回配信からの経過期間で見た場合（観測期間が足りない企業は除外し、打ち切りバイアスを回避）：

| 経過   | 企業数 | 当たり率 | 配信本数の中央値 | 累積PV中央値 | 累積PV上位10% |
| ------ | ------ | -------- | ---------------- | ------------ | ------------- |
| 3か月  | 22,018 | 13%      | 1本              | 21           | 95            |
| 6か月  | 21,322 | 14%      | 2本              | 27           | 130           |
| 12か月 | 20,100 | 16%      | 2本              | 35           | 209           |
| 24か月 | 17,834 | 19%      | 3本              | 47           | 383           |
| 36か月 | 15,680 | **23%**  | **4本**          | 58           | 591           |

**3年経っても23%にしかならない。** 本数で見た場合の87%とは大きな差がある。

理由は明確で、**中央値の企業は3年かけて4本しか配信していない**から。
つまり時間の経過そのものには効果がなく、その間に何本出したかがすべて。

この対比が、このプロダクトの最も強いメッセージになる。

> ✕ 続けていればいつか成果が出る
> ◯ 出した本数の分だけ確率が上がる。放置している時間は何も生まない

## 6. 打ち手ごとの効果差分（情報通信・756,600本）

「当たり」＝業種内PV上位10%に届いたこと。同一業種内で比較しているので規模の影響は抑えられている。

### メイン画像 ― 最も差が大きい

|          | 件数    | 当たり率  | PV中央値 |
| -------- | ------- | --------- | -------- |
| 画像あり | 733,704 | **10.3%** | 12       |
| 画像なし | 22,896  | **4.4%**  | 8        |

**約2.3倍。** 単一の打ち手としては最大。しかも設定の有無はDBから機械的に判定できるため、
「使っていない企業に対して、数字つきで指摘できる」という点で実装価値が高い。

### キーワード設定 ― 単調に効く

| 設定数  | 件数    | 当たり率  | PV中央値 |
| ------- | ------- | --------- | -------- |
| 0件     | 43,661  | 6.3%      | 9        |
| 1〜2件  | 17,872  | 7.7%      | 9        |
| 3〜5件  | 112,609 | 8.5%      | 10       |
| 6件以上 | 582,458 | **10.8%** | 12       |

0件と6件以上で**約1.7倍**。件数が増えるほど単調に上がる。

### タイトルの書き方

|                      | 件数    | 当たり率  |
| -------------------- | ------- | --------- |
| 【】を含む           | 118,738 | **11.8%** |
| 数字を含む           | 399,920 | **11.3%** |
| 「」を含む           | 419,347 | 10.4%     |
| 【】なし             | 637,862 | 9.9%      |
| 数字なし             | 356,680 | 8.9%      |
| **～で補足している** | 47,891  | **7.9%**  |

数字あり／なしで約1.3倍。**「～」でタイトルを補足しているものは逆に低い**（7.9%）のが意外な発見。

タイトルの長さはほとんど効かない（25字未満9.0% → 70字以上10.5%）。

### 配信の曜日

| 曜日   | 件数       | 当たり率   |
| ------ | ---------- | ---------- |
| 日     | 7,870      | 13.7%      |
| 土     | 13,453     | 12.5%      |
| 金     | 152,177    | 10.4%      |
| 月〜木 | 各12〜16万 | 9.9〜10.1% |

土日が高いが、**件数が平日の1/10以下**であり、休日に配信する企業は運用が丁寧という
選択バイアスの可能性が高い。**因果として提案するのは避けるべき。**

### 配信の時間帯

| 時刻 | 件数    | 当たり率 |
| ---- | ------- | -------- |
| 8時  | 23,361  | 11.8%    |
| 10時 | 132,727 | 11.5%    |
| 9時  | 47,524  | 11.1%    |
| 11時 | 138,552 | 10.0%    |

朝の配信がやや高い。ただし曜日と同様に選択バイアスの疑いがあり、扱いは慎重に。

### まとめ：提案の優先順位

| 打ち手              | 効果      | 検出の容易さ                |
| ------------------- | --------- | --------------------------- |
| メイン画像を付ける  | **2.3倍** | ◎ `main_image` の NULL 判定 |
| キーワードを3件以上 | 1.7倍     | ◎ `release_keyword` の件数  |
| タイトルに数字      | 1.3倍     | ◎ 正規表現                  |
| タイトルに【】      | 1.2倍     | ◎ 部分一致                  |
| 配信の曜日・時間帯  | 判断保留  | ○ ただし因果と断定できない  |

## 6-2. 一度止まってから再開した企業（最重要）

**「もう一度やってみよう」を支える唯一の材料。** 方法論ではなく実例が人を動かす。

6か月以上の空白のあとに再開した企業を、休止前の配信本数で分けて追跡した（情報通信）。

| 休止前の本数 | 企業数    | 休止前の当たり率 | **再開後の当たり率** | 再開後に追加した本数（中央値） |
| ------------ | --------- | ---------------- | -------------------- | ------------------------------ |
| **1本**      | **4,291** | 9%               | **44%**              | **3本**                        |
| 2〜3本       | 2,667     | 12%              | 48%                  | 4本                            |
| 4〜10本      | 1,995     | 19%              | 53%                  | 6本                            |
| 11本以上     | 1,264     | 42%              | 67%                  | 10本                           |

**1本で止まった企業が4,291社も再開しており、たった3本追加しただけで44%が手応えを得ている。**

### 空白期間の分布

| 空いていた期間 | 再開した企業 |
| -------------- | ------------ |
| 6〜9か月       | 2,382        |
| 9〜12か月      | 1,672        |
| 1〜2年         | 3,492        |
| **2年以上**    | **2,671**    |

情報通信の22,748社のうち **10,217社（45%）が一度止まってから戻ってきている**。
2年以上あけて再開した企業も2,671社。**「今さら」は成立しない。**

### 目標設定への使い方

この数字があると、目標が「87%を目指す」ではなく **「あと3本」** になる。

> あなたと同じく1本で止まった企業が4,291社。そのうち再開した企業は、
> 中央値でたった3本を追加しただけで、44%が手応えのある結果に届いています。
> 月1本なら3か月、3か月に1本のペースでも9か月です。

**達成可能で、根拠があり、小さい。** これが本プロダクトの中心メッセージ。

## 6-3. 同一企業内の前後比較（バイアスを消した検証）

第6章の効果差分は企業間の比較なので、「丁寧な企業ほど機能を使う」という
選択バイアスを排除できていなかった。そこで**同じ企業の中で**前後を比較した。

**途中からメイン画像を使い始めた企業（情報通信・1,663社）**

|                  | 当たり率 |
| ---------------- | -------- |
| 使い始める**前** | **1.7%** |
| 使い始めた**後** | **8.1%** |

条件：画像なしのリリースが2本以上、画像ありが2本以上ある企業のみ。

同じ企業の中で約4.8倍。**企業間のバイアスは排除できた**が、
「後になるほど運用が上手くなる」という時間トレンドの影響は残る。
それでも企業間比較（2.3倍）より強い証拠になっている。

## 6-5. 設定と当たり率（機能の採否を決めるための検証）

### 地域指定 — 差がある。ただし因果ではない

|              | 本数    | 当たり率  |
| ------------ | ------- | --------- |
| 地域指定あり | 125,699 | **13.9%** |
| 地域指定なし | 630,901 | **9.4%**  |

約1.5倍。指定しているのは全体の16%にとどまる。

**「地域指定なし＝悪」ではない。** 全国に届けたい企業のほうが多いはずで、
相手が地域を意識していると明示したときにだけ出す。

### カテゴリ数 — 「増やす」ことに意味は無かった

| カテゴリ数 | 本数    | 当たり率  |
| ---------- | ------- | --------- |
| **0件**    | 16,141  | **0.4%**  |
| 1件        | 149,235 | **10.9%** |
| 2件        | 591,010 | 10.2%     |
| 3件以上    | 214     | 0.5%      |

**当初の想定（拾われる経路が増えるから多いほど良い）は誤り。**
1件と2件でほぼ差がなく、むしろ微減している。

意味があるのは **0件かどうかだけ**。0件と1件で 0.4% → 10.9%、約27倍。
3件以上は214本しかない例外で、判断材料にならない。

→ 提案は「カテゴリを増やす」ではなく「**未設定のリリースがある**」に限定する。

## 6-6. 短期での達成率（勧めない判断の材料）

初回配信から3か月以内（情報通信・22,028社・平均配信2.3本）：

| 目標                             | 達成した企業 |
| -------------------------------- | ------------ |
| 1本でも50PV以上（業種内上位10%） | **12.5%**    |
| 1本でも200PV以上                 | **2.4%**     |
| 1本でも1000PV以上                | **0.3%**     |
| 累計500PV以上                    | 1.2%         |

**3か月で1000PVは1000社に3社。**

この数字の使い方は「無理です」と言い切ることではない。
**達成率をそのまま見せて、判断を相手に委ねる。**

> 「3か月以内に200PV以上に届いた企業は2.4%でした。
> 　この期間で確実に数字が要るなら、広告など別の手段のほうが向いているかもしれません。」

公開されている統計には存在しない数字なので、ここがプロダクトの特色になる。

## 7. この分析は公開されていない

調べた範囲では、PR TIMESが自社データを集計してこの種の統計を公開している事実は確認できなかった。

公開されているのは以下の程度：

| 公開されている数値             | 出典                           |
| ------------------------------ | ------------------------------ |
| 月間PV 約9,000万（サイト全体） | PR TIMES 会社情報              |
| 提携メディア 205媒体           | 同上                           |
| 転載先の目安「20媒体以上」     | PR TIMES MAGAZINE 効果測定記事 |

PR TIMES MAGAZINE のノウハウ記事は**操作方法と見方の解説が中心**で、
「配信本数別の成功率」「打ち手ごとの効果差分」といった集計値は出ていない。

なお「転載先20媒体以上」という記述は、本分析の実測（大多数が21〜100件）と整合している。

**したがって、本分析で得た数値はこのプロダクト固有の資産になる。**

## 8. パフォーマンス上の注意

| クエリ                            | 所要時間                     |
| --------------------------------- | ---------------------------- |
| 当たり率カーブ（業種1つ）         | 約2秒                        |
| 種別ごとの傾向（業種1つ）         | 約9秒                        |
| 期間ごとの推移（業種1つ）         | 約15秒                       |
| 打ち手の効果差分（業種1つ）       | 約30秒                       |
| 再開企業の追跡（業種1つ）         | 約11秒                       |
| 同一企業内の前後比較（業種1つ）   | 約11秒                       |
| キーワード別の当たり率（業種1つ） | **約61秒**（事前計算が必要） |

`release_statistic` にインデックスが無いため、業種単位でも重い。
実装では**業種ごとに30分キャッシュ**し、初回のみ待たせる方式にした。

**サーバー起動時に `DEFAULT_COMPANY_ID` の業種を自動で温める処理を入れた**ため、
起動から約40秒後にはすべて即答できる状態になる。

## 9. 未解決・今後

- **資本金による規模の絞り込みは未使用。** 業種だけで2万社あるため現状は不要だが、
  「同じ規模の企業だけで見る」を足すと納得感は上がる
- **当たりの閾値（上位10%）は暫定。** 上位20%や上位5%でカーブの形がどう変わるかは未検証
- 業種は17種類しかなく粒度が粗い。`business_category` を併用する余地がある
- **曜日・時間帯は選択バイアスの切り分けができていない。** 打ち手として提案するなら、
  同一企業内での比較（同じ企業が平日に出したものと休日に出したもの）で確認する必要がある
- 打ち手の効果はすべて相関であり、因果ではない。画像を付ける企業はそもそも丁寧、という
  可能性は排除できていない。**提案時は「差がある」と述べ、「上がる」と断定しない**
